Pac-Man for PS5

This project was developed by Jordan Allard and Runi Jiang for the Console Development graduate course at RIT (IGME 753). The demo is coded in C++ for the PlayStation 5, using a PlayStation devkit provided by the course. A simple recreation of Pac-Man, this project provided experience in programming for consoles and the PlayStation devkit environment.
